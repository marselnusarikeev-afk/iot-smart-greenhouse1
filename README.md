# IoT Smart Greenhouse

Веб-платформа управления теплицей: мониторинг датчиков, автоматика полива/вентиляции/освещения, тревоги, аналитика и рекомендации.

## Запуск
Откройте `index.html` в браузере (сервер не нужен).

## Структура
- `data.js` — зоны, типы датчиков, навигация, пороги, график на canvas
- `storage.js` — состояние в localStorage
- `simulator.js` — симулятор датчиков (шаг каждые N секунд)
- `automation.js` — правила автоматики и ручное управление
- `alerts.js` — формирование и обработка тревог
- `analytics.js` — средние значения, график, рекомендации
- `dashboard.js` — страницы панели, зон, датчиков, управления, настроек

## Как это работает
Симулятор меняет показания → автоматика включает устройства по порогам → система создаёт тревоги → аналитика строит выводы. Пороги задаются в «Настройках».
